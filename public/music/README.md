# Custom race music

Drop an MP3 here named after a theme to replace that theme's generated music:

| File | Theme |
| --- | --- |
| `sunny.mp3` | Sunny Speedway |
| `neon.mp3` | Neon Nights |
| `candy.mp3` | Candy Canyon |
| `glacier.mp3` | Glacier Run |
| `volcano.mp3` | Volcano Rush |

Tracks loop. They play quieter while betting and louder during the race. Use music you have the rights to — royalty-free libraries such as Pixabay Music work well.
